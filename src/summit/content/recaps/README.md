# Cross-session recaps

Only add completed, approved-for-publication JSON here. Files are discovered automatically; no registry edit is needed. **Do not commit confidential or unapproved drafts**: this repository and its Git history are public. `status: "draft"` prevents application/preview publication but cannot make a committed file private.

See [the recap publishing reference](../../RECAPS.md) for the schema, example and workflow. No recap articles ship with this infrastructure change. Test data belongs under `test-fixtures/` or in temporary files removed by tests, never as production records in this directory.
